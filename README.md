# מרכז שליטה

מתכנן יומי בעברית שנפתח כמו אפליקציה בטלפון: משימות, שלושה דברים למיקוד של היום, טיימר מיקוד, הרגלים, לימודים וציונים, יעדים, פתקים וסקירה שבועית.

## התקנה בטלפון
1. פותחים את כתובת האתר ב-Chrome (אנדרואיד) או ב-Safari (אייפון).
2. אנדרואיד: תפריט ⋮ ← "הוספה למסך הבית" או "התקנת אפליקציה". אייפון: כפתור השיתוף ← "הוספה למסך הבית".
3. פותחים מהאייקון. מהפעם השנייה האפליקציה עובדת גם בלי אינטרנט.

## איפה הנתונים
הנתונים נשמרים רק במכשיר שבו משתמשים, בדפדפן. אין חשבון, אין שרת, ושום דבר לא נשלח לשום מקום.
מי שפותח את הכתובת ממכשיר אחר מקבל אפליקציה ריקה.

בגלל זה כדאי להוריד גיבוי מדי פעם: הגדרות ← "הורד גיבוי". שחזור: הגדרות ← "ייבוא מקובץ".

## מה יש בתיקייה
- `index.html` – כל האפליקציה בקובץ אחד (HTML, CSS ו-JavaScript, בלי ספריות חיצוניות)
- `manifest.webmanifest` – שם, צבעים ואייקון להתקנה כאפליקציה (PWA)
- `sw.js` – Service Worker שמאפשר עבודה בלי אינטרנט
- `icons/`, `fonts/` – אייקונים וגופנים (IBM Plex Sans Hebrew ו-Karantina, ברישיון SIL Open Font License)
